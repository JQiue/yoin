# 简介

Yoin 是一个**可嵌入的评论系统**：后端提供 HTTP API，前端是一个能挂到任意网页上的评论组件（widget），另带一个管理后台。前后端编译在同一个二进制里，部署时只有一个进程和一个数据库。

## 能做什么

- 多级评论：顶层评论 + 回复
- 表情反应，可按站点裁剪可用表情
- 置顶、删除
- 匿名评论、私密评论（仅作者本人与站点管理员可见）
- 游客评论：未登录访客也能发言，靠浏览器里的游客身份区分
- 邮箱注册/登录，以及 GitHub / QQ 第三方登录
- 站点级设置：评论长度、发帖间隔、匿名/私密开关、可用表情
- 评论审核：可接 LLM 审核，命中后进入待审
- 成员与权限：超级管理员 / 站点管理员 / 审核员
