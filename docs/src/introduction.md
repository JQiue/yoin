# 简介

Yoin 是一个**可嵌入的评论系统**：后端提供 HTTP API，前端是一个可以挂到任意网页上的评论组件，另带一个管理后台。前后端一起编译进同一个二进制，部署时只有一个进程和一个数据库。

## 组成

| 部分 | 说明 | 入口 |
| --- | --- | --- |
| 服务端 | Axum + SeaORM，默认 SQLite | `cargo run` |
| 评论组件 | Preact 组件，挂载到宿主页面的某个容器里 | `/static/client.js` |
| 管理后台 | Preact 应用，站点/评论/权限/提供商管理 | `/static/admin.js` |

## 能力

- 多级评论（顶层评论 + 回复，按 `thread_id`/`parent_id` 组织）
- 表情反应，可按站点裁剪可用表情
- 置顶、删除，权限由 RBAC 判定
- 匿名评论、私密评论（仅作者本人与站点管理员可见）
- 游客评论：未登录访客用 `guest_id` 维持身份
- 站点级配置：评论长度、发帖频率、匿名/私密开关、可用表情
- 账号体系：邮箱注册/登录（JWT）、GitHub / QQ 第三方登录
- 审核提供商：LLM 审核（可选按站点配置）

## 当前状态

版本 `0.0.1`，属于草稿阶段：核心的评论、反应、站点配置、RBAC、OAuth、审核链路已经打通，但管理后台的部分页签和 Akismet 审核尚未完整实现（见 [评论审核](moderation.md)）。以 [CHANGELOG](https://github.com/JQiue/yoin/blob/dev/CHANGELOG.md) 为准。
