# 站点设置

站点是评论的归属单位：同一个站点的评论共享一份配置。在管理后台的「站点」页可以新建站点、改站点名称和地址，以及调整下面这些开关。

## 可以调什么

| 设置项（后台里的名字） | 默认 | 它意味着什么 |
| --- | --- | --- |
| Anonymous comments | 允许 | 读者可以隐藏身份发言（仍会记录游客身份用于自身的删除权限） |
| Private comments | 允许 | 读者可以发只有自己（和站点管理员）能看到的评论 |
| Max comment length | 1024 | 评论正文的字符上限，超出直接拒绝 |
| Rate limit (seconds) | 60 | 同一个访客/账号在该站点内的发帖间隔，防止连发 |
| Allowed reactions | 五个全开 | 该站点允许出现的表情，从 👍 ❤️ 😄 🎉 👎 里挑 |

- 关掉匿名/私密之后，读者在评论框里就看不到对应的开关了；即使绕过界面直接提交，服务端也会拒绝；
- 发帖间隔按「站点 + 身份」计算：登录用户按账号算，未登录访客按来源 IP 算；
- **站点管理员不受**长度、间隔、匿名/私密这四项限制，方便自测和维护。

## 站点编号

站点的编号（`id`）就是嵌入评论时 `site_id` 要填的值，在「站点」页的列表里能看到。第一个注册账号会自动获得一个默认站点（编号 1）。

## 谁能改

- 超级管理员：所有站点；
- 站点管理员 / 审核员：只对绑定到自己的站点生效（见[成员与权限](members.md)）。

## 需要精确取值时

后台里每个开关对应的字段名、默认值和接口返回结构，统一记录在开发者指南的 [HTTP API · 站点配置](../dev/http-api.md#站点配置) 一节。
