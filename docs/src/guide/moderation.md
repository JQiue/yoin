# 审核评论

## 评论的四种状态

| 状态 | 含义                                 |
| ---- | ------------------------------------ |
| 待审 | 还没有结论，前台不显示               |
| 通过 | 正常展示                             |
| 垃圾 | 判定为垃圾，前台不显示，也不能被回复 |
| 删除 | 已删除（数据保留，便于追溯）         |

前台评论列表只展示**通过**的评论。

## 什么情况下会进入待审

- 站点**没有**启用审核提供商：新评论直接通过；
- 站点**启用**了审核提供商：新评论先记为待审，随后由提供商判定并自动回写结果。

用 LLM 审核时，判定结果与状态的对应关系是：

| 提供商结论      | 结果                         |
| --------------- | ---------------------------- |
| 允许            | 通过                         |
| 需要人工看      | 停留在待审                   |
| 拒绝            | 垃圾                         |
| 调用失败 / 超时 | 停留在待审（不会误判为垃圾） |

已经人工处理过的评论不会被异步结果覆盖。

## 配置 LLM 审核

后台 → 「Moderation providers」 → Add moderator，按站点填写：模型名、API Base、API Key，以及审核规则（会拼进提示词里，用来描述你的站点标准）。同类型的提供商按站点各配一份。

> **Akismet 尚未实现**：界面上可以添加，但配了之后不会真的审核，评论会一直停在「待审」。要过滤评论请用 LLM。

## 人工审核

后台 → 「评论」页：按站点、页面地址、状态筛选，逐条改状态。可以只处理待审的，也可以把误判为垃圾的捞回来。

需要「审核评论」权限（审核员、站点管理员、超级管理员都有）。

## 谁能看到什么

- **私密评论**：只有作者本人（登录账号或同一个游客身份）和该站点的管理员能看到；其他人访问会得到「不存在」，不会泄露内容；
- **匿名评论**：普通访客看不到真实身份信息，站点管理员可以看到；
- **删除**：作者可以删自己的评论；持有「删除任意评论」权限的人可以删任何评论；
- **置顶**：需要该站点的管理权限，且只能置顶顶层评论。
